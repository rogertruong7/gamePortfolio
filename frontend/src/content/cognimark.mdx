## About Cognimark

Cognimark, based in Boston, reads the records healthcare practices already keep and tells their teams who needs follow-up. When I worked on it, the platform's focus was dementia assistance.

This was my first placement through Lyra, working as a forward-deployed engineer for three months. My work had two halves: getting patient data into the platform reliably, and building the application clinical teams used to manage it.

## Ingesting patient data

Electronic health records arrive from outside systems in large batches, so an import has to survive interruptions and partial failures. I architected a serverless pipeline for multi-tenant healthcare clients:

- **API Gateway** is the entry point.
- **Step Functions** coordinates the stages of a job.
- **Lambda** does the processing.
- **S3** holds the data.

Three things made it dependable:

- **Resumable job tracking**, so an interrupted job can carry on rather than start again.
- **Fault-tolerant NDJSON assembly**, so bulk records are built up safely.
- **Batch conflict resolution**, which retries on HTTP 409 responses.

This accelerated ingestion throughput by 60%.

## Removing duplicate records

The same patient data can arrive more than once, and duplicates in a health record cost money and make the record harder to trust. I designed deterministic FHIR R4 deduplication inside the Step Functions pipelines. It cross-references patient records before persisting them to each tenant's PostgreSQL database.

Being deterministic means the same input always gives the same result, which matters when you need to be able to explain why a record was kept or dropped.

This reduced EHR data duplication by 40% across three healthcare organisations, saving an estimated $15,000 a year in wasted storage and manual reconciliation.

## The clinical management app

I delivered a full-stack application that three organisations, such as AthenaHealth, integrated to manage 5,000+ patient records.

| Layer | What I used |
| --- | --- |
| Backend | Django REST Framework, with Celery for async task queues |
| Frontend | Vue 3, with TanStack Query for server state and Pinia for client state |
| Auth | AWS Cognito JWT authentication |
| Data | Multi-tenant database routing, so each organisation's requests reach its own database |
