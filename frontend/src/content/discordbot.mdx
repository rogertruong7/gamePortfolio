## What it does

A Discord bot I built in Node.js with discord.js, using `!` prefix commands:

| Command | What it does |
| --- | --- |
| `!help` | Shows the command list in an embed |
| `!blackjack` | Starts a hand against the dealer |
| `!gunfight @user` | Challenges someone to a typing race |
| `!exit` | Leaves the current game |

It also replies with a song lyric whenever someone says "oh no".

## Blackjack

The game is played in an embed with Hit and Stand buttons.

1. A deck is an array of 52 card values. Drawing picks a random index and retries if that card has already been dealt.
2. The player and the dealer each get two cards, with one of the dealer's hidden.
3. Each button's custom ID includes the player's user ID, so only the person playing can press it.
4. Each press replies with an updated embed showing the new cards and score.
5. When the player stands, the dealer's second card is revealed and the dealer draws until reaching at least 17.

## Gunfight

`!gunfight @user` picks a random word with the `random-words` package and runs a countdown in the channel using `setTimeout`. The first of the two players to type the word wins.

## What it doesn't do

I planned this as an economy bot with balances and bets stored in MySQL, but I stopped before building that part. The database folder only has an empty SQL file and a connection test, and the help text still advertises a bet that isn't wired up.

Game state is held in variables in the running process, so the bot handles one blackjack game at a time across all servers, and a restart loses it. A per-user game record in a database is what I'd add first.
