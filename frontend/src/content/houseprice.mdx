## What it does

A single Python script that takes a training CSV and a test CSV, then solves two problems in a row:

| Task | Type | Model | Metric | Output file |
| --- | --- | --- | --- | --- |
| Sale price | Regression | XGBoost | Mean absolute error | `houses.regression.csv` |
| Property type | Classification | Random Forest | Weighted F1 | `houses.classification.csv` |

The repository includes the data: 5,016 training rows and 1,067 test rows. Each one combines facts about the property (bedrooms, bathrooms, parking, size, date sold) with facts about its suburb (median income, median prices and rents, distance from the CBD, public housing share) and wider figures such as the cash rate.

## Cleaning the data

Both tasks share the same cleaning steps:

1. **Fix formats.** Percentages stored as text, like `"15%"`, become decimals.
2. **Drop sparse columns.** A column goes if more than 40% of its values are missing or effectively missing, which includes `0` and `0%`.
3. **Drop sparse rows.** A row goes if more than 60% of its values are missing in the same sense.
4. **Reduce skew.** Numeric features with an absolute skew above 0.3 get a `log1p` transform.

## Predicting price

Numeric columns get mean imputation and standard scaling. Categorical columns get a constant fill value and one-hot encoding, ignoring categories that weren't in the training data. Identifiers and a few low-value suburb columns are removed first.

The regressor optimises absolute error directly with `reg:absoluteerror`, matching the metric the script reports:

| Setting | Value |
| --- | --- |
| Trees | 900 |
| Learning rate | 0.07 |
| Max depth | 4 |
| Min child weight | 12 |
| Row and column sampling | 0.8 and 0.9 |
| L1 and L2 regularisation | 0.8 and 4 |

The shallow depth, regularisation and sampling all work against overfitting.

## Predicting type

The classifier uses numeric features only, with mean imputation and scaling, and a Random Forest of 105 trees with a minimum of 3 samples to split. Both models are scikit-learn pipelines, so the same preprocessing runs at training and prediction.
