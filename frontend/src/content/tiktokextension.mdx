## What it does

TikTok's mobile app lets you hold on a video to play it at 2x, and the website didn't have an equivalent. This extension adds one. Hold the left mouse button on a video and it speeds up with a small indicator on screen, and let go to return to normal speed. A popup has an on/off toggle.

I published it on the Chrome Web Store in 2024. To try it now, load the code as an unpacked extension. It only asks for the `storage` permission and access to `tiktok.com`.

## How it works

It's a Manifest V3 content script with three small parts:

| File | Job |
| --- | --- |
| `observer.js` | Wraps the Mutation Summary library to watch the page for new video elements |
| `script.js` | Finds the current video and handles the hold |
| `popup.js` | Saves the toggle with `chrome.storage.sync` |

## The details that mattered

### Telling a hold from a click

A normal click on a TikTok video pauses it, so the speed can't change as soon as the button goes down. The script records when the button was pressed, and a `requestAnimationFrame` loop only sets `playbackRate` to 2 once the press has lasted 300 milliseconds.

### Handling videos that come and go

TikTok is a single-page app, so videos are added and swapped without a page load. Listening on one video element wouldn't survive scrolling to the next. Instead:

1. The observer calls `checkPage` whenever a `video` element appears.
2. `checkPage` finds the active video with the selector `video[data-xgplayerid]` and stores it in a variable.
3. The mouse listeners sit on `document` and are added only once, guarded by a flag, so they don't stack up as videos change.

### Working out what was pressed

A listener on `document` hears every press on the page, so it has to decide whether this one was on the video. It compares the mouse position with the video's `getBoundingClientRect`.

### Reacting to the toggle

The content script listens to `chrome.storage.sync.onChanged`, so the popup's toggle takes effect in an open tab without a refresh.
