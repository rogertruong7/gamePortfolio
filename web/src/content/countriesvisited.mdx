## What it does

This is a REST API, called myTravelHistory in its docs, for keeping a record of where you've travelled. You send a two-letter country code and the years you visited, and the service fills in the rest of the details itself. Flask-RESTX serves an interactive Swagger page at the root URL, which is the easiest way to try it.

| Method and path | What it does |
| --- | --- |
| `PUT /countries/<code>` | Adds or replaces a country. Returns 201 if it's new and 200 if not |
| `GET /countries/<code>` | Reads one country |
| `PATCH /countries/<code>` | Adds years to a country, merging them with what's stored |
| `DELETE /countries/<code>` | Removes a country |
| `GET /countries` | Lists countries with filters, sorting and pagination |
| `GET /countries/visited` | Returns a PNG of charts about your travel |

## Filling in country data

A `PUT` sends a GraphQL query to a public countries API for the name, native name, flag emoji, capital, continent, languages and currencies. The request has a 5 second timeout, and a timeout comes back to the client as a 504. An unknown code gets a 404, and anything that isn't two letters is rejected with a 400 before any network call.

## Querying JSON in SQLite

Languages, currencies and years are lists, so I stored them as JSON text in a single `countries` table. Filtering then uses SQLite's `json_each` inside an `EXISTS` subquery, with the value bound as a parameter:

```sql
SELECT * FROM countries
WHERE 1=1
  AND EXISTS (
    SELECT 1 FROM json_each(countries.years_visited)
    WHERE json_each.value = ?
  )
```

Each filter that's present (continent, currency, language or year) adds its own clause to the query.

## Sorting and pagination

`sort` takes a comma-separated list such as `continent,-last_updated`, where a leading `-` means descending. I apply Python's stable sort once per key, starting from the last key, which gives the same result as a multi-column `ORDER BY`.

Responses include hypermedia links. A single country links to itself and to the previous and next countries by code, and a list links to the previous and next pages with your filters preserved.

## Charts

`GET /countries/visited` draws three pie charts with Matplotlib: visits by country with the years listed, by continent and by year. It renders to an in-memory buffer and streams the PNG, using the headless Agg backend so it works on a server. With no data it returns a 204.
