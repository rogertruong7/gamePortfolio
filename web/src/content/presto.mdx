## What it is

Presto is a React frontend for making slide decks, inspired by Google Slides. It started as a university team project in 2024, and most of the commits on it are mine. The frontend was deployed to Vercel, but the backend behind it no longer responds, so signing in doesn't work and there's no live demo to link to.

## What you can do

- **Dashboard.** Create and delete presentations, and edit each one's title, description and thumbnail.
- **Slide editor.** Add and delete slides, and move between them with the sidebar or the arrow keys.
- **Four element types.** Text, images, videos and code.
- **Themes.** Set a slide's background to a solid colour, a gradient or an image, for one slide or as the deck's default.
- **Fonts.** Pick a font for a text box from a dropdown.
- **Preview.** Present the deck on its own page and step through it with the arrow keys.

## How it's built

### Routing

The slide number is part of the URL (`/:id/edit/:slideNumber` and `/:id/preview/:slideNumber`), so refreshing keeps your place and a link can open on a specific slide. A `ProtectedRoute` component sends signed-out users away from the dashboard.

### Elements

Each element type has a block component that renders it and a settings panel that adds or edits it. Width, height and position are stored on the element and set through that panel. Double-clicking an element opens its settings, and that's handled by timing clicks in a 500 millisecond window.

- **Code blocks** detect their language with highlight.js's automatic detection, then render through `react-syntax-highlighter`.
- **Images** can be uploaded, converted in the browser to a data URL with `FileReader` and stored with the deck.

### Saving

The backend has a single store per user, read with `GET /store` and replaced with `PUT /store`. Every edit follows the same pattern: fetch the store, change the presentation, write the whole thing back, then update React state. That kept the client logic simple, and it means a large data URL gets sent with every save.

### Tests

Vitest and Testing Library cover the homepage's rendering and initial animation styles.
